public subroutine calc_chi_cold(species, omega, kpar_d, kperp_d, va_ref_c, chi, ierr)

Return ordinary chi_s, without identity or wave-matrix terms. Used inputs must be finite; mu_s and va_ref_c positive, Q_s nonzero, D_s nonnegative. Signed Q_s determines the signed gyrofrequency. Zero density returns zero after input validation. For populated species, exact frequency, Doppler and cyclotron poles return distinct statuses. Every error returns quiet NaNs; the caller must inspect ierr. No temperature, anisotropy, collision rate or global state is read.
