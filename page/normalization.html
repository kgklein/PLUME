We use as a symbol for the temperature definition d_ref tauS in this manual to avoid confusing a physical temperature with the inverse ratio in rho_ref. Both use the same Fortran input name. Self ratios for the reference population are mu_1=Q_1=D_1=1. The solver does not enforce self-ratio or reference-density consistency; unusual component decompositions require a clearly specified reference density. There is no automatic renormalization.

Scan paths

Caveat: One of the useful aspects of PLUME is the ability to serially or in parallel scan dispersion relation solutions over wavevector and plasma parameters. Generally, the user can select any sets of parameters for these scans. The exception is for a beta_R and theta_s d_ref scans. By definition for the d_ref normalization, changing beta_R also updates theta_1. A reference theta_1 scan updates beta_R in return. Varying both independently in a 2D scan is rejected. A beta-only rho_ref scan traces different a different physical system than that in d_ref. Convert every point, including endpoint and interpolation rules, before making a physical comparison.

Cold references and the auxiliary thermal scale

Cold-containing calculations require selecting the d_ref normalization. For a cold reference use betap=0 and species_1 tauS=0. All species may be cold, or some may be kinetic. No physical reference thermal speed or gyroradius exists in that limit, but , and remain finite.

For warm species with a cold reference, the existing kinetic algebra uses an internal positive scale selected from the first warm species' theta. It constructs auxiliary beta , thermal velocity over c, , wavevector ), inverse temperature , and normalization anisotropy . The physical is unchanged. This is simply a coordinate transformation. Fully cold calculations bypass this thermal conversion entirely.

There is no public /auxiliary-temperature namelist control. Reordering warm non-reference populations can change the internally chosen scale, but results should remain physically equivalent within the documented numerical conditioning.
